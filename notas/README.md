# notas

As notas originais do projeto, em português, de antes de existir código.

**São história, não documentação.** Ficaram no repositório porque registram *por que* o
projeto é como é — a decisão de escrever em Rust, a de publicar sob copyleft, a regra que
está acima de todas as outras:

> no pior caso, se quebrar, nao podemos impedir o computador de dar boot

O que elas descrevem nem sempre é o que foi construído. `arquitetura.md` fala de um
`raba-set-theme`, por exemplo, e o que existe é `raba-setup --set-theme`. Onde as notas e
a documentação discordam, a documentação está certa:

- [`docs/`](../docs) — a referência, em inglês, mantida junto com o código
- [`docs/milestones.md`](../docs/milestones.md) — o que foi construído, em que ordem, e o
  que cada passo custou
- [`CHANGELOG.md`](../CHANGELOG.md) — o que está em cada versão

Nada aqui é atualizado quando o código muda.
